# Tools

Tools is a library that attempts to make a unified codebase for windows and linux functions (while also understanding their differences)

Tools primary goal is to make sure that each possible case in any function is accounted for, with any errors that occur are given specific and easily discernable so developers can easily understand what error occurred

Tools currently covers the following:
- networking: ethernet with multiple classes to easily implement higher level protocols, TCP
- filesystem
- permissions: mainly implemented for linux with plans to add for windows
- cryptography: RSA, AES, and XOR
